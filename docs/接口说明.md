# PortCall HTTP接口

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 商业咨询微信 zhuatech / zhuatech2。

同源`/api` JSON与会话。先GET `/auth/csrf`取得header／token，写请求带对应头及Cookie；POST `/auth/login` username／password。GET `/auth/me`，POST `/auth/logout`及`/auth/password`（oldPassword／newPassword）。无固定公开密码。

| 路由 | 输入或返回 |
| --- | --- |
| GET /options、/dashboard | 范围内表单目录／统计 |
| GET /calls、/changes、/services、/vessels、/agencies | search、status、kind、page从0、size1～100、sort为newest／reference；items及total |
| GET /calls/{id}、/changes/{id}、/services/{id} | record和events；挂靠含范围内services，非提供方含changes |
| POST／PUT /calls[/{id}] | requestKey、version更新、reference、vesselId、agentId、location、eta、etd |
| POST／PUT /changes[/{id}] | requestKey、version、reference、callId、baseRevision、eta、etd |
| POST／PUT /services[/{id}] | requestKey、version、reference、callId、providerId、kind、critical、windowStart、windowEnd |
| POST／PUT /vessels[/{id}]、/agencies[/{id}] | requestKey、version、reference、name、departmentId、enabled；机构kind为AGENT／PROVIDER |
| DELETE /vessels/{id}、/agencies/{id} | 仅未引用目录 |
| GET /{calls\|changes\|services}/{id}/report.json | export权限、同详情范围、no-store下载，无推广载荷 |
| GET /audit | 内部范围审计，SELF仅本人，机构禁止 |

POST `/{calls|changes|services}/{id}/commands/{action}`：requestKey为UUID，version为当前版本，note为证据备注，实际动作含at，重排含windowStart／windowEnd。时间带时区ISO8601，统一UTC微秒。

| 对象 | action |
| --- | --- |
| calls | submit、approve、reject、arrive、depart、close、cancel |
| changes | submit、approve、reject、cancel |
| services | request、confirm、decline、replan、start、report、accept、dispute、cancel |

成功含record。相同账号、目标、动作及内容的精确UUID重试返回已处理结果，改内容REQUEST_KEY_REUSED；旧版本STALE_VERSION；非法状态INVALID_STATE；未闭合UNRESOLVED_WORK。失败事务不占用UUID。客户端遇冲突应刷新详情。

管理GET／POST／PUT／DELETE `/admin/{users|roles|departments|permissions|menus|dictionaries|settings}`，增删受目录具体规则限制。用户username、displayName、password只写、roleId、departmentId、agencyId、enabled；角色name、scope、permissions。权限菜单只用注册code，字典类型service，系统参数名称固定。保留一个启用ALL且未绑定机构的内部管理员。

400输入／时间错误，401无效会话，403权限／范围／绑定／CSRF，409版本／状态／独立人员／UUID／关联冲突。错误code／message不含栈或密码。健康`/actuator/health`无业务数据。机构绑定覆盖ALL，服务端每次核验。
